## Accepted Scope (added to the design doc)
- **Eval pass targets:** resolution ≥ 80% on the 20 answerable questions, 5/5 escalates
  on the 5 unanswerable, hallucination proxy = 0. Stop condition for verifier tuning;
  pass/fail meaning for the published numbers. Under the cut line, targets scale to the
  trimmed fixture: ≥ 10 of 12 answerable resolved, 3/3 unanswerables escalated,
  hallucination proxy still = 0.
- **Next Step 1 addition:** read the handoff demos in `tsjdev-apps/maf-demo-console`
  before writing the stub prototype.
- **`ask` output additions (CEO review decision: one shared result object feeds all
  three surfaces — CLI renders, MCP exposes as fields, DevUI displays):** one line per
  ask (model calls · wall-clock · estimated cost); on escalate, a compact per-claim
  table (claim / verdict / chunk evidence) drawn from the existing claims JSON.
  Cost basis: token usage when the client reports it, else
  character approximation vs a static price table; prints "— (non-default model)" when
  `CS_AGENT_DRAFT_MODEL`/`CS_AGENT_VERIFY_MODEL` are overridden — a static table cannot
  price BYO models.
- **Local-filesystem resilience:** ingest skips unreadable/binary files with a warning
  and reports skip counts; corrupt `.db` → structured delete-and-re-ingest error;
  corrupt recency-pointer auto-rebuilds (never a silent wrong-corpus answer);
  the recursive loader carries a symlink-cycle guard and depth cap.
- **Trust boundary:** v1's trust boundary is the corpus owner = the operator; the
  design doc now states it, and the post-publish URL-mode spec inherits a named
  corpus-poisoning consideration (crawled pages are untrusted input to the verifier).
- **README addition:** "Learn MAF" resources section — official samples, DevUI docs,
  the community repos above — home of the corrected novelty claims.
- **Test additions:** MCP round trip asserts the result-object fields
  (`claims[]`, `estimated_cost`); `eval` exits 0 on pass / 1 on miss against the
  pass targets — the stop condition for verifier tuning and the seam the deferred
  CI gate plugs into.
- **`--json` flag:** `cs-agent ask --json` prints the shared result object
  verbatim — machine-readable CLI surface, and the CLI-vs-MCP fidelity check.
- **Progress line:** during the model calls, `ask` prints stage labels
  (retrieving → drafting → verifying) to stderr, TTY-gated — the interactive
  wait is legible; stdout and `--json` stay machine-clean.
