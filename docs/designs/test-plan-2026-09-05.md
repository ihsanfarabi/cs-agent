## Affected Pages/Routes
- `cs-agent ingest <url|path>` — crawl/load → chunk → embed → SQLite store; the store must survive killed runs
- `cs-agent ask "<question>"` — full pipeline: Triage → Draft → Verify → resolved (with citations) or Escalation (`missing[]`)
- `cs-agent eval` — 25-question fixture through the same ask pipeline; 3 metrics
- MCP server (stdio) — same workflow wrapped for Claude Code

## Key Interactions to Verify
- Resolved path on `ask`: answer prints with citations, verdict computed before any output (no streaming)
- Escalate path on `ask`: unanswerable question returns `missing[]`, draft is NOT printed
- Verifier rule branching: all-supported / any-unsupported / zero-claims / malformed-retry-fail-closed
- Handoff graph in DevUI: Draft → Verify edge and Verify → Escalation edge both visibly fire
- `ingest` re-run after a killed crawl resumes without re-embedding committed pages

## Edge Cases
- Missing `CS_AGENT_MODEL_KEY` — structured error, no stack trace
- Invalid API key, 429, timeout — structured errors naming the failing call and env var
- Empty store on `ask` — structured "no documents ingested" error
- Ingest finding zero crawlable pages / nonexistent path
- Chunker: tiny input, exact 1200-char boundary, overlap-150 continuity
- Malformed verifier JSON twice → fail closed to escalate

## Critical Paths
- Cold-machine quickstart: install tool → ingest fixtures → cited answer, under 5 minutes
- Unanswerable question escalates instead of hallucinating (the thesis)
- Eval numbers measure the same pipeline `ask` runs
